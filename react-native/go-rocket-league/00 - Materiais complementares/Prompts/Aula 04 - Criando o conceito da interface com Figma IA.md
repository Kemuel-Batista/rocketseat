## 🟢 PROMPT 1 

> Design a realistic, high-fidelity mobile app UI for a game called “GoRocketLeague”. Theme: football + rocket exploration + world map. Dark mode, modern, game-like interface. The app has 5 main tabs: Map, Collection, Trades, Achievements, Profile. The Map screen is the core experience, with a full-screen dark world map, floating HUD showing rocket fuel, XP and level, subtle discovery signals, and a scan interaction to reveal hidden player cards. Cards are collectible, unique, and organized by national teams. Include smooth animations, card reveal moments, fuel indicators, and a premium game UI feel. The UI should look production-ready, clean, and intuitive, designed for a React Native mobile app.

---

### 🧠 resposta (IA FIGMA)

I've created a production-ready, high-fidelity mobile game UI for GoRocketLeague featuring a dark, modern aesthetic with smooth animations and premium game elements. The app includes all 5 tabs with the Map screen as the core experience—complete with an interactive world map, floating HUD showing rocket fuel and XP, pulsing discovery signals, and an animated scan interaction that reveals collectible player cards. Each card has rarity-based styling and a dramatic reveal animation with particle effects. The Collection, Trades, Achievements, and Profile screens are fully designed with intuitive layouts and game-like polish.

Key features implemented:

Animated tab navigation with smooth transitions
Interactive map with scan mechanics and fuel consumption
Card collection system organized by national teams
Premium UI with gradients, glows, and 3D effects
Mobile-optimized responsive design centered in viewport
